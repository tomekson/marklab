Co je ve vašem textu schované a co s tím jde udělat

Vložte český text, nechte ho zanalyzovat a očistit. Všechno v režimu Prohlížeč běží lokálně, text nikam neodchází.

Deterministické Unicode cleanup: odstraní zero-width znaky, tag znaky, exotické mezery, bidi kontroly. Stejný výsledek při každém běhu, ověřitelný inspekcí.
Experimentální Statistická mitigace: přepis textu modelem. Nedeterministická, u češtiny může změnit význam a neexistuje veřejný detektor, který by potvrdil odstranění produkčního vodoznaku Claude nebo Gemini.

      Tyto reporty vznikly spuštěním všech pěti pipeline (2 deterministické, 3 statistické) přes Python bridge. Stavy unsupported u statistických pipeline jsou záměrné: bez lokálního modelu nástroje nic nepřepisují a nic netvrdí.
      
    
      
  
      

  
      
    
      Jak to funguje
      
    
        
      
      1. Analýza: inspekce Unicode politikou dewatermark (verze politiky je v reportu). Nálezy mají tři stupně: actionable (odstranit), contextual (nahradit mezerou), informational (legitimní kontext, zachovat).
        2. 
      
      2. Očištění: safe profil zachová emoji joinery, bidi v RTL kontextu a variační selektory; přísný profil smaže všechny zbývající formátovací znaky. České pevné mezery se po očištění vrací zpět.
        3. 
      
      3. Ověření: stejná inspekce nad výstupem. Stav unicode_verified znamená jen „politika už nic nehlásí“, ne „text je bez vodoznaku“.
        4. 
      
      4. Statistika (jen s bridge): přepis modelem přes watermarks-remover, dewatermark remove nebo reverse-SynthID-text. Výstup je vždy mitigation_unverified, dokud ho neověří kompatibilní nezávislý detektor.
        5. 
    
      
    
      Zdroje: dewatermark (MIT) · watermarks-remover (MIT) · reverse-SynthID-text (Apache-2.0) · kód tohoto dashboardu
